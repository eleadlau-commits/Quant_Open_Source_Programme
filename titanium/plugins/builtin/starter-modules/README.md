# Starter modules

The starter folder of the module library: momentum, moving-average trend, top N equal weight.

## What it adds

- modules: `starter/Momentum`, `starter/Above moving average`, `starter/Top N equal weight`

## What it needs

Nothing beyond the core. Switch it off in Settings > Plugins; the rest of the app carries on.

## Check it

```
python -m titanium.plugins check titanium/plugins/builtin/starter-modules
```
